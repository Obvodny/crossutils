# CrossBox

CrossBox is a cross-platform collection of POSIX utilities. While similar in spirit to BusyBox and Toybox, it has a distinct objective. Leveraging the capabilities of the modern C/C++ standard library, CrossBox implements cross-platform tools using *only* the standard library—eschewing conditional compilation and system-specific dependencies. The goal is to explore the limits of what can be achieved with pure standard C/C++.
